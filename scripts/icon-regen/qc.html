Pass criteria (issue #96 acceptance criteria):
  • Mark reads clearly at 180 / 192 / 512 px, and as a favicon at 16–48 px (browser chrome).
  • Maskable variants keep all ink inside the 80% safe-zone circle (dashed red overlay) and survive the common OS masks (circle, rounded square, squircle previews below).
  • Palette stays on the manifest theme colors (cobalt #1E4D73, cream #F6F1E8, background #f3eee6).
  • No watermark / AI artifacts; original hand-authored geometry (or, for the Mistral arm, license-clean output per Mistral ToS — no attribution phrase).
  • PNG dimensions exact (180/192/512, square), regular icons opaque, byte size in the same ballpark as current (8–24 KB).
